## C · Long post (if @memoh_ai has Premium / long-post access, 478)

What is a Bot, and how many can I create?

In Memoh, a Bot is an agent instance with its own cloud computer: its own desktop, files, dependencies and memory.

You can create different Bots for different jobs, say one for scheduling and reminders and another just for development. Bots are fully isolated from each other and never get in each other's way.

Your plan determines how many Bots you can create and how much compute each one gets. See pricing: https://memoh.ai/#pricing
